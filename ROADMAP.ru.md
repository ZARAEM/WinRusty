# WinRust: планы

(English version: [ROADMAP.md](ROADMAP.md))

У каждого пункта указано, насколько он проверен: **тесты** (юнит-тесты), **собрано** (компилируется, не запускалось), **запускалось** (руками на живой системе), **сквозная** (полная установка/удаление на живой системе).

## Сделано

### Установщик
- Исправления после ревью (v0.3.0): rs-du хранит список карантина рядом со своим exe (писать туда может только администратор), `payload\` двумя уровнями выше берётся только из `target\release`, rtaskmgr и rust-explorer сохраняют и возвращают чужие настройки диспетчера задач и папок, rust-search сначала возвращает поиск Windows и только потом удаляет свои файлы, DiagTrack оставлен debloat, один разбор вывода `reg query` с тестом. *тесты, собрано*
- Параметры без Проводника (Win+I и меню панели): Параметры — Store-приложение, оно открывается только при Проводнике в роли оболочки, поэтому скрытый помощник запускает Проводник, ждёт его панель, открывает страницу, выводит окно на передний план (в том числе поверх полноэкранной игры) и возвращает rust-explorer после закрытия Параметров; зависший процесс Параметров сначала убивается. Панель скрывается только для полноэкранных игр и видео. *собрано, проверено вручную*
- Один `plugin-launcher.exe`, в который вшиты все плагины (распаковка в Program Files, не в %TEMP%), статический CRT, тёмное окно на Win32/GDI. *запускалось*
- «Install WinRust» ставит недостающее по порядку (topbar раньше rust-explorer), когда всё стоит, обновляет; «Удалить всё» удаляет в обратном порядке. *собрано*
- Сбой установки откатывает свои изменения (кроме обновления рабочей копии); исходные значения (WSearch, строка поиска, настройки Проводника, службы) сохраняются в `HKLM\SOFTWARE\plugin-launcher\<плагин>` и возвращаются при удалении; несмертельные ошибки пишутся в `%ProgramData%\plugin-launcher\install.log`. *собрано*
- Точка восстановления перед установкой. *собрано*
- Выбор, что ставить (#7): в окне галочка у каждого компонента, в командной строке несколько имён или `all`; упавший или пропущенный компонент не останавливает остальные, ошибки перечисляются в конце. Отсутствие службы Windows Search (урезанные сборки LTSC) для rust-search при установке и удалении теперь предупреждение, а не ошибка. *собрано*
- Пользователь сеанса, а не элевированная учётная запись (#4): если в UAC введён другой администратор, пользовательские настройки (HKCU, задачи планировщика, профиль PowerShell, право на канал rust-search, Run-ключ rs-launcher, HKCU-политики debloat) пишутся владельцу explorer.exe (или topbar / rust-explorer / rs-shell) этого сеанса через `HKU\<SID>`. Если пользователя определить нельзя, установка останавливается до любых записей. Удаление продолжается с предупреждением. *тесты (подмена ключей), собрано*
- Одна кнопка ставит недостающее **и** обновляет установленное: запуск нового `WinRust.exe` доносит исправления до всех плагинов (v0.2.1). *собрано*
- Командная строка: `list | install <плагин>...|all --yes | update <плагин> | uninstall <плагин> | rollback --yes`, коды выхода 0/1/2; окно и командная строка вызывают одни и те же функции. Запускались только команды, которые ничего не меняют. *запускалось (частично)*
- `update` и `scripts\update-plugin.ps1`: переустановка из `payload\` на диске без пересборки установщика. *запускалось*
- Английский по умолчанию, переключатель Русский/English в установщике и в меню панели; выбор хранится в `%ProgramData%\WinRust\lang.txt`. *тесты*
- Устройство кода: один cargo workspace; установщик разделён на `install/` (файл на плагин), `cli.rs`, `ui.rs`; общий crate `winrust-common` (переключатель языка, чтение MFT); один список `payload.txt` для сборки и скриптов; CI на GitHub Actions. *тесты*

### Плагины
- **rust-search**: служба поиска по NTFS + Alt+Space; отключает WSearch, блокирует SearchHost.exe, прячет строку поиска. Правый клик по результату: переименовать, в корзину, «удалить навсегда + почистить реестр» (сканирование → подтверждение → удаление; реестр сначала сохраняется в `%LOCALAPPDATA%\rs-search\registry-backups\*.reg`). *тесты, запускалось*
- **rtaskmgr-win32**: заменяет диспетчер задач через IFEO-Debugger (`taskmgr.exe` не трогается); при панике пишет `%APPDATA%\rtaskmgr\crash.log` и открывает настоящий Taskmgr. *тесты, запускалось*
- **topbar**: нижняя панель в стиле Windows 11 вместо панели задач; `topbar.exe --restore` возвращает панель задач. Вместе с ним ставятся хоткеи reshell, rs-du, блок профиля PowerShell (`src/install/profile.ps1`, Windows PowerShell 5.1 и pwsh 7). *запускалось; блок профиля только на временном профиле*
- **Страховка reshell**: если topbar не запущен, а панель задач скрыта, два раза подряд (~10 с), запускает `topbar.exe --restore`. *тесты; сценарий «убить topbar» не проверялся*
- **Хоткеи reshell**: Win+D (показать рабочий стол) и Win+I (Параметры) работают без Проводника, как Win+E (v0.2.1). *запускалось*
- **Стили** (v0.3.0): шестерёнка в левом краю панели переключает Обычный / Терминал / Плавающий док / Тайлинг; панель, rust-explorer и окно поиска перекрашиваются сразу (широковещательное сообщение, `%ProgramData%\WinRust\style.txt`). Док не занимает места на экране и уезжает из-под развёрнутых окон; Тайлинг ставит панель наверх и умеет раскладывать окна плиткой. *запускалось*
- **Вид topbar** (v0.3.0): значок сети рисуется сам (дуги Wi‑Fi по сигналу, крестик без сети, «!» без интернета, по данным Windows о подключении); новая панель Wi‑Fi (статус, карточка подключённой сети с отдельной кнопкой «Отключиться», сохранённые и открытые сети, строки появляются по очереди); меню только из текста с подсказками клавиш; выбор языка ввода (левый клик по ENG/RUS); трей проявляется с анимацией, стрелка поворачивается. *запускалось*
- **Микшер громкости** (форк): левый клик по динамику открывает микшер по приложениям, как в EarTrumpet: общий уровень, затем каждое приложение, которое играет звук, со своим ползунком, отключением звука (клик по значку) и живым индикатором уровня внутри ползунка; ниже список устройств вывода, клик делает устройство основным. Колесо над строкой приложения меняет его громкость, средний клик по динамику выключает звук, правый открывает быструю панель, как раньше. Упрощения: первые восемь приложений и шесть устройств, без прокрутки; смена устройства идёт через недокументированный `IPolicyConfig`. *тесты (имена, затухание индикатора), собрано; на Windows не запускалось*
- **Перетаскивание кнопок панели** (форк, #6): кнопку приложения можно зажать и перетащить: закреплённые двигаются среди закреплённых (порядок хранится в `%APPDATA%\topbar-pins.txt`), кнопки окон среди кнопок окон (пока окна открыты). Соседи плавно отъезжают, и весь ряд плавно сдвигается, а не прыгает, когда окно открывается или закрывается. Кнопки приложений теперь срабатывают при отпускании кнопки мыши. Средний клик или Shift+клик по запущенному приложению открывает ещё один экземпляр, как на панели задач Windows (раньше средний клик закрывал окно). *тесты (слот вставки, сохранённый порядок, шаг скольжения), собрано; на Windows не запускалось*
- **Миниатюры окон** (форк): если задержать указатель на кнопке запущенного приложения, над панелью появляются живые миниатюры его окон (миниатюры DWM, со значком и заголовком окна); клик переключает на окно, крестик или средний клик закрывает его. При движении вдоль панели миниатюры сменяются сразу. Клик по кнопке с несколькими окнами, ни одно из которых не впереди, показывает миниатюры на выбор, а не поднимает первое. Упрощение: столько миниатюр, сколько помещается по ширине экрана, без прокрутки. *тесты (вписывание миниатюры), собрано; на Windows не запускалось*
- **Ещё от панели задач Windows** (форк): окно, которое просит внимания (`FlashWindow`), мигает оранжевым на своей кнопке, затем кнопка остаётся подсвеченной, пока окно не откроют; кнопки появляются, исчезают и меняют отметку активного окна в тот же момент, что и окно (события shell hook, с Проводником и без него), а не при следующем опросе раз в полсекунды; полоска на дальнем краю панели показывает рабочий стол, повторное нажатие возвращает окна; правый клик по «Пуску» открывает меню Win+X (системные инструменты, Терминал, Диспетчер задач, «Выполнить», Рабочий стол); Ctrl+Shift+клик по кнопке приложения запускает его от имени администратора. *тесты (кривая мигания), собрано; на Windows не запускалось*
- **Перетаскивание значков трея** (форк): значки, оставленные на панели, можно перетаскивать в другом порядке (хранится в `topbar-tray.txt`, остальные плавно отъезжают); значок, брошенный на стрелку, уходит обратно в выпадающее окно. Значки трея на панели теперь срабатывают при отпускании кнопки мыши. *тесты (слот вставки), собрано; на Windows не запускалось*
- **Один общий ряд и перетаскивание, поднимающее окно** (форк): закреплённые и кнопки окон теперь можно перетаскивать в любом порядке между собой, как на панели задач Windows 11 (порядок закреплённых сохраняется; место окна живёт, пока окно открыто; новая закреплённая встаёт после последней закреплённой, новое окно в конец). Если держать что-то, перетаскиваемое из другой программы (файл, текст, вкладку), над кнопкой приложения около полсекунды, его окно выходит вперёд, и туда можно бросить. *тесты (слияние ряда), собрано; на Windows не запускалось*
- **Показ окна и прогресс** (форк): если задержать указатель на миниатюре окна на полсекунды, показывается только это окно, остальные становятся прозрачными контурами (Aero Peek, через недокументированный экспорт 113 из dwmapi); когда панель сама оболочка (без Проводника), прогресс, который приложение сообщает панели задач (`ITaskbarList3`: загрузки, копирование, установка), рисуется вдоль низа его кнопки: зелёный, жёлтый на паузе, красный при ошибке, бегущий отрезок, когда длительность неизвестна. Оба опираются на недокументированные внутренности Windows, известные по другим заменам панели задач, а не на что-либо увиденное здесь: это первое, что надо проверить на настоящей машине. *тесты (шкала прогресса), собрано; на Windows не запускалось*
- **Недавние файлы, микрофон, перетаскивание из окна трея** (форк): меню правого клика по кнопке приложения показывает до пяти недавно открытых файлов, для которых это приложение программа по умолчанию (по папке «Недавние» и сопоставлениям файлов; клик открывает файл); в микшере есть блок микрофона (уровень, отключение и другие микрофоны на выбор); значок трея можно перетащить из выпадающего окна на панель, чтобы он остался там (значки в окне теперь срабатывают при отпускании кнопки мыши). *тесты (расширение недавнего файла), собрано; на Windows не запускалось*
- **Мелкие привычки панели задач** (форк): Shift+правый клик по кнопке приложения открывает системное меню окна; задержка указателя на полоске «показать рабочий стол» показывает стол сквозь окна; только что запущенная закреплённая кнопка покачивается, пока не появится окно; подсказка батареи говорит, сколько осталось; второй вовремя сделанный клик по значку трея отправляется как двойной, а проход указателя над значком сообщается его приложению; ползунок микрофона в микшере показывает живой уровень, пока что-то записывает. *собрано; на Windows не запускалось*
- **Настройки панели** (форк): в меню шестерёнки три переключателя, хранятся в `%APPDATA%\topbar-settings.txt`: кнопки слева, а не по центру; скрывать панель автоматически (она не резервирует место на экране, уезжает через 0,8 с после ухода указателя и возвращается у края экрана, для «Пуска», панелей и миниатюр); секунды в часах. *собрано; на Windows не запускалось*
- **Кнопки по приложению, а не по exe** (форк): окна группируются так же, как на панели задач Windows: по идентификатору, который объявляет само окно (приложения Store внутри ApplicationFrameHost, веб-приложения, установленные из браузера, отдельные профили браузера), иначе по упакованному процессу, иначе по exe; закреплённые кнопки с таким идентификатором берут окна именно этого приложения. Незакреплённые окна одного приложения теперь делят одну кнопку (раньше: кнопка на окно), и эта кнопка сохраняет место, пока открыто хоть одно окно приложения. Окна других виртуальных рабочих столов и раньше не показывались (они скрыты системой). *тесты (сопоставление закреплённых), собрано; на Windows не запускалось*
- **rust-explorer**: файловый менеджер (вкладки, иконки, копирование/вставка/удаление через IFileOperation, контекстное меню, перетаскивание), рисует рабочий стол, отключает Проводник как оболочку через `rs-shell --overlay` (не позже 90 с после входа: Windows 26300 больше не пишет отметки автозагрузки, которых он ждал, v0.2.1), урезает службы. *тесты, запускалось*
- **rs-du**: чистильщик диска (анализ MFT, кеши, `target`/`node_modules`, корзина, карантин на 30 дней), запускается из меню панели. *тесты*
- **wiztree**: карта занятого места по MFT. *тесты (только раскладка); на живом диске не запускался*
- **photoview**: просмотр фото на WIC, поворот по EXIF, пункт «Открыть с помощью». *запускалось; EXIF-ориентации 5 и 7 не проверялись*
- **debloat**: службы и политики (телеметрия, Copilot, Recall, реклама, фоновый Edge), старые значения в `%ProgramData%\winrust-debloat\undo.txt`, `--undo`. *сухой прогон запускался; `--apply`/`--undo` нет*
- **purge**: удаляет предустановленные Store-приложения (установленные и из образа) и задачи телеметрии, как Tiny11; OneDrive и Edge только с `--onedrive` / `--edge`. НЕОБРАТИМО, журнал в `%ProgramData%\winrust-purge
emoved.txt`. `purge.exe` показывает список, `--ask` просит ввести YES (меню по правому клику на панели), `--apply` удаляет. Защищённые имена (Магазин, Параметры, Пуск, среды выполнения) проверены тестами. *тесты, пробный запуск выполнен; `--apply` не запускался*

## Дальше (по порядку)
0. **Телефоны и безопасное извлечение в rust-explorer** (#2): не начато, для быстрой правки слишком много. (а) У MTP/PTP-телефонов нет буквы диска, поэтому нужен Windows Portable Devices API (`IPortableDeviceManager`, `IPortableDeviceContent`, перечисление объектов, чтение и запись через потоки `IPortableDeviceResources`) как вторая «файловая система» в rust-explorer рядом с путевой; копирование, вставку, удаление и перетаскивание придётся переделать под неё. (б) Безопасное извлечение: значок в трее topbar (трей там уже есть), список съёмных дисков и `CM_Request_Device_Eject` для узла выбранного диска (сначала сброс буферов, при «занято» показать, какой процесс держит). Часть (б) меньше и работает для флешек и дисков; (а) это то, о чём в основном issue. Для проверки нужны настоящий телефон и флешка: одними юнит-тестами не обойтись.
0. **Запустить изменения панели из форка на Windows**: микшер, перетаскивание кнопок и миниатюры окон написаны и проверены только компилятором на Linux (`cargo check --target x86_64-pc-windows-msvc`). Проверить в первую очередь: микшер с несколькими играющими приложениями, смену устройства вывода, перетаскивание при одной закреплённой кнопке, перетаскивание в момент закрытия окна, миниатюры свёрнутых окон и окон с правами администратора, события shell hook при работающем Проводнике, каждый пункт меню Win+X.
0. **Ближе к панели задач Windows** (форк), в таком порядке: (в) перестановка значков внутри выпадающего окна трея; (г) значки-накладки на кнопках (`ITaskbarList3::SetOverlayIcon`: значок приходит через общую память в недокументированном сообщении) и прогресс при работающем Проводнике; (д) остальное от списка переходов: собственные задачи и закреплённые элементы приложения (его хранилища `AutomaticDestinations` / `CustomDestinations`) и недавние файлы для приложений, которые не являются для них программой по умолчанию; (е) панель на каждом мониторе; (ж) список уведомлений за часами; (и) перенос одного приложения на другое устройство вывода (Windows держит это за недокументированным `IAudioPolicyConfig`).
0. **Больше движения** (форк): свёрнутое / развёрнутое состояние кнопки, значки трея и подсказки пока меняются мгновенно; при закрытии окна кнопка могла бы исчезать так же плавно, как появляется.
1. **Проверка на чистой Windows 11 в виртуалке**: установка, удаление, откат, перезагрузка, по каждому плагину. На другой машине пока ничего не проверялось.
2. **Один журнал отката для всех плагинов**: каждое изменение (значение реестра, служба, файл) записывается как «было → стало» до того, как сделано; удаление и откат проигрывают журнал назад. Заменяет ручной uninstall каждого плагина. Сначала нужен шаг 1 и миграция для установок текущей версии.
3. **Реестр через Win32 API** (`RegGetValueW`/`RegSetValueExW`) вместо запуска `reg.exe` и разбора его вывода.
4. **Релизы**: SHA-256 рядом с exe, версия в окне, проверка обновлений.
5. **Подпись кода** (убирает предупреждение SmartScreen и часть ложных срабатываний антивирусов).
6. **Профиль PowerShell**: по желанию ставить rg/fd/bat/eza/zoxide через winget (галочка в настройках topbar).
7. **chrome-rs**: настоящая установка, когда браузер будет готов (см. `plugins/chrome-rs/ROADMAP.md`).
8. **Win+S / кнопка «Пуск»** открывают rust-search вместо поиска Windows (рискованно, отдельное решение).
9. **Не-NTFS диски** в rust-search (сейчас пропускаются).

## Известные ограничения
- Системные компоненты отключаются или обходятся (обратимо), а не удаляются: удаление `taskmgr.exe` или поиска Windows сломало бы защиту системы.
- Нужны права администратора.
- Win+S и «Пуск» по-прежнему открывают поиск Windows.
